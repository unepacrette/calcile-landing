# Calcile Landing

Next.js (Pages Router) landing page, waitlist, and beta workspace for
Calcile — bilingual (FR/EN) via `lib/i18n.tsx`.

Calcile is built on open-source. We respect all licenses. If you spot a
dependency, license, or attribution issue, open an issue or reach out at
